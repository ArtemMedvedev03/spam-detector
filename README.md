# Определитель спама на русском языке

Русская версия учебного проекта. Пользователь вставляет русскоязычное письмо,
программа анализирует текст, выводит «СПАМ / НЕ СПАМ» и сохраняет результат в SQLite.
Интерфейс, примеры, инструкции и собственные сообщения об ошибках — на русском.

## Запуск в Windows

1. Распакуйте ВЕСЬ архив в отдельную папку. Не запускайте файлы внутри ZIP.
2. Откройте папку `spam_detector`.
3. Дважды щёлкните `01_install.bat`. Дождитесь надписи **ГОТОВО**.
   Нужен установленный Python 3.14 и интернет для установки библиотек.
4. Дважды щёлкните `02_start.bat`. При первом запуске автоматически обучится
   русская модель. Дождитесь появления окна.
5. Нажмите «Пример спама», затем «Проверить письмо». Повторите с обычным письмом.
   Для своего текста используйте кнопку «Вставить текст», Ctrl+V или меню по правой
   кнопке мыши. Сочетания Ctrl+A/C/V/X/Z/Y в Windows работают и в русской раскладке.
6. Вставьте своё русское письмо. «История и статистика» открывает пять вкладок
   с результатами SQL-запросов. «Результаты тестирования» показывает метрики.

Установка выполняется один раз. Для следующих запусков используйте `02_start.bat`.
После установки интернет не нужен. Содержимое писем никуда не отправляется.
Команды pip при установке могут выводить служебные сообщения на английском.

## Если запуск не получился

Не удаляйте Python или Python Launcher. Сделайте скриншот сообщения об ошибке.
Установщик ищет Python 3.14 через `py -3.14`, затем в стандартной папке установки,
затем через `python` в PATH. Поддерживаемые версии: Python 3.11–3.14.
Для ручного запуска откройте командную строку в папке проекта:

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

Если Python 3.14 вызывается через `py -3.14`, используйте эту команду вместо
`python` в первой строке. Можно также указать полный путь к `python.exe` в кавычках.
Команды вводятся в терминале, а не в окне IDLE с `>>>`.

Вычислительная часть проверена на Python 3.12.14 и scikit-learn 1.8.0.
Запуск графического окна и BAT-файлов на Windows нужно проверить на вашем ПК:
в среде сборки нет Windows и графического дисплея.

`tkinter`, `sqlite3`, `csv`, `json`, `pathlib`, `re` — стандартные модули Python.
Через pip устанавливаются scikit-learn, joblib и их зависимости.
На Linux/macOS используются `.venv/bin/python` и установленный Tkinter.

## Что умеет программа

- Принимать русский текст, в том числе со словами Python, Telegram и другими
  иностранными названиями внутри письма.
- Определять класс по содержимому, без подключения к почте и проверки отправителя.
- Показать оценку спама моделью. При оценке от 35% до 65% появляется подсказка
  проверить письмо вручную. Это условная зона неуверенности интерфейса;
  она не меняет порог классификации 50% и не является статистическим интервалом.
- Сохранять тексты и результаты в локальной БД и показывать историю.
- Обрабатывать пустой ввод, слишком длинный текст и текст без русских слов.

## Данные и ограничения

Для обучения использован открытый набор **ZhiznMart Spam Classification** автора
`necrasov-ilya`. Это 5648 сообщений из русскоязычного Telegram-чата,
размеченных как спам и не спам. Источник, версия и лицензия CC BY 4.0 указаны
в `data/SOURCE.md`; исходная карточка набора сохранена рядом.
В этой версии Enron не используется. Машинно переведённые SMS и искусственно
составленные письма в обучающую выборку не добавлялись.

После исключения 6 строк без кириллицы и 564 повторов нормализованного текста
осталось 5078 сообщений: 2552 обычных и 2526 спам-сообщений. Нормализация
объединяет различия в регистре, «ё/е», пунктуации и числовых значениях.
Все повторяющиеся нормализованные тексты удаляются ДО разделения данных.

80% сообщений (4062) используются для обучения, 20% (1016) — для итогового теста.
Разбиение стратифицированное, `random_state=42`. TF-IDF обучается только на
обучающей части. Выбор между Байесом и логистической регрессией сделан отдельно
на валидации внутри обучающих 80%, без использования итоговых тестовых ответов.

На итоговом тесте: accuracy 97,34%, precision 96,14%, recall 98,61%, F1 0,9736.
**Это метрики на сообщениях из чата, а не доказанная точность на электронной почте.**
Данные относятся к одному сообществу. Похожие, но не одинаковые формулировки могут
попасть в разные части. Разделение не проверяет перенос между чатами и во времени.
Фильтр может ошибаться на деловой переписке, уведомлениях и фишинговых письмах.
Оценка в процентах отдельно не калибровалась и не является гарантией.
Программа не проверяет вложения, ссылки, домены, подлинность отправителя или вирусы.

Дополнительно выполнены 12 авторских сценариев русских писем и сообщений,
включая обычную переписку и спам. Все результаты, в том числе ошибки, сохранены
в `scenario_results.json`. Эти сценарии не использовались для обучения и не
заменяют независимый почтовый тестовый корпус.

## База данных

`models` хранит модель и метрики, `emails` — введённые тексты,
`predictions` — результаты. Внешние ключи связывают результат с моделью и письмом.
Схема допускает много проверок одной моделью и много проверок одного письма;
интерфейс на каждое нажатие создаёт отдельную запись письма и один результат.
Письмо и результат записываются одной транзакцией с параметризованными запросами.
Пять SELECT-запросов: история, спам, число проверок по классам, по дням и по моделям.
Время в базе и истории — UTC, что указано в подписях.
